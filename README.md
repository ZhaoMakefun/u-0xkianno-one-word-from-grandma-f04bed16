Exactly one word Grandma would text about AI: "Beepboop" — the baffled, warm little robot noise she makes when her grandchild tries to explain the machines. One word, instantly readable, tied to robots rather than any subject at all, and funny without a caption.

## Run it

```sh
python3 main.py
```

Writes the 8-character word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Python 3.13, standard library only, no network, deterministic.
